# Changelog

## 1.0.0 - 2026-08-29

Initial usable release.

- Cross-platform Python CLI
- Exact-host scope enforcement and non-local authorization acknowledgement
- Security header, cookie, CORS, TLS, technology disclosure, security.txt, and robots.txt checks
- Bounded requests, redirects constrained to scope, and conservative timeouts
- JSON and escaped self-contained HTML reports
- Automated tests
- CI matrix for Linux, Windows, and macOS
- MIT license, security policy, and contribution guide
